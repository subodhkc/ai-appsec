# Security Policy

## Status

AI AppSec is a public prerelease. The current supported version is 0.1.0-rc.1.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in AI AppSec:

1. **Do not disclose it publicly** before it has been reviewed.
2. Report it via [GitHub private vulnerability reporting](https://github.com/subodhkc/ai-appsec/security/advisories/new).
3. For non-sensitive bugs, use [GitHub Issues](https://github.com/subodhkc/ai-appsec/issues).

## Scope

- This policy applies only to the `ai-appsec` repository
  (https://github.com/subodhkc/ai-appsec).
- Related repositories (LLMVerify, Tenant Isolation, HAIEC website) have their
  own security policies.
- Vulnerabilities in Semgrep itself should be reported to Semgrep, Inc.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.0-rc.1 | YES (current prerelease) |
| < 0.1.0-rc.1 | NO (pre-release development) |

## Bounty

No bug bounty program exists for this project at this time.

## Response Expectations

This project is maintained by a small team. We aim to acknowledge reports
within 5 business days. We appreciate your patience and responsible disclosure.
