# Phase 4B — Adoption-First Distribution Recommendation

## Business objective

ADOPTION FIRST.

## Requirements

- One-command install
- No account
- No API key
- No source upload
- No telemetry
- Offline execution after install
- Agent can invoke immediately
- HAIEC provenance/branding retained

## Recommendation

**BUNDLE THE QUALIFIED PUBLIC CORE WITH THE FREE PACKAGE**

This is Option A from the distribution options document.

## What becomes source-visible

- Public Core rule definitions (YAML)
- Detector IDs and security check IDs
- Rule messages and metadata
- Manifest structure

## What remains defensible HAIEC IP/moat

- Advanced checks (future paid tier)
- Organization-specific policies
- Central evidence/history (SaaS)
- Custom rules engine
- Team control plane
- Managed rule updates
- Scan Receipt and proof-of-fix infrastructure
- Integration with Tenant Isolation and LLMVerify

## Status

**DO NOT implement irreversibly without explicit founder approval.**

This is a recommendation, not a decision. The founder must approve
before Public Core rules are bundled and published.
